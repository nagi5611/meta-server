**文書バージョン**: 1.0  
**最終更新**: 2026-06-22  
**対象アドオン**: `addons/webxr-vr`  
**UI ライブラリ**: [three-mesh-ui](https://github.com/felixmariotto/three-mesh-ui)

関連ドキュメント:

- [Meta Quest / WebXR 利用メモ](../WEBXR_QUEST.md)
- [webxr-vr README](../../addons/webxr-vr/README.md)

## 1. 概要

### 1.1 背景

VR 没入中は 2D の `#menu-bar` や `#chat-container` が操作しづらい。DOM Overlay は Quest の `immersive-vr` で不安定な報告があり、HTML をそのまま重ねる方式は正としない。

### 1.2 目的

Meta Quest 風の操作感を目指し、**左手 Y ボタン**で画面下部に 3D メニューバーを表示する。通常メニュー機能とチャットを 1 か所に集約し、各項目からサブパネル（ポップアップ）を開けるようにする。

### 1.3 基本方針

| 項目 | 方針 |
|------|------|
| UI 描画 | three-mesh-ui（3D 空間 UI） |
| ビジネスロジック | 既存 `MenuManager` / `ChatManager` を再利用・委譲 |
| 実装場所 | 原則 `addons/webxr-vr/client/` に集約 |
| 2D UI | VR 中は非表示または操作無効。VR 終了後は従来どおり |

---

## 2. 確定仕様（ステークホルダー決定事項）

以下は実装前に確定した要件である。

| # | 項目 | 決定内容 |
|---|------|----------|
| D-01 | ビデオ配信 | **VR ユーザーはビデオ配信できない**。VR メニューにビデオ項目は出さない（または常時無効・非表示） |
| D-02 | チャット入力 | **Quest システムキーボード**を使用する |
| D-03 | 設定パネル | **全項目を実装**する。実装が困難な項目は **UI のみ**（操作は無効または「VR 非対応」表示）とする |
| D-04 | 絵文字（スタンプ） | **チャットとは独立したパネル**として表示する |
| D-05 | テレポート | **メニュー表示中はテレポートしない** |
| D-06 | 起動ボタン | **初版は左手 Y ボタンのみ**。Menu ボタン（左手 index 7）対応は **P5 以降** |

---

## 3. スコープ

### 3.1 対象（In Scope）

- VR セッション中（`renderer.xr.isPresenting === true`）のみ有効
- 左手 **Y ボタン**によるメインメニューの表示／非表示トグル
- 画面下部に横並びアイコンメニュー（three-mesh-ui）
- 既存 `#menu-bar` 相当機能の VR 統合（**ビデオ除く**）
- チャットを VR メニュー項目として統合（常時フローティング表示は VR 中やめる）
- 各項目からサブパネルを開閉
- メニュー表示中のテレポート抑止
- i18n（ja / en / zh）

### 3.2 対象外（Out of Scope）

- 非 VR（PC / モバイル 2D）UI の変更
- VR でのビデオ配信（カメラ・画面共有）
- 手トラッキング操作
- 初版での Menu ボタン割り当て
- DOM Overlay への依存

## 4. ユーザーストーリー

| ID | 内容 |
|----|------|
| US-01 | VR 中、左手 Y を押すと画面下にメニューが現れ、もう一度押すと消える |
| US-02 | メニューからマイク／スピーカーをトグルでき、状態がアイコンに反映される |
| US-03 | 「チャット」を押すとチャットパネルが開き、Quest システムキーボードで入力・送信できる |
| US-04 | 「スタンプ」を押すと絵文字専用パネルが開き、選択した絵文字が送信される |
| US-05 | 「設定」を押すと既存設定モーダルと同等の全セクション・全項目が VR パネルで見える |
| US-06 | メニュー表示中、右トリガーによるテレポートが発動しない |
| US-07 | VR 終了後、2D の `#menu-bar` / `#chat-container` が通常どおり使える |

## 5. 入力・操作要件

### 5.1 Y ボタン（メインメニュートグル）

| 項目 | 仕様 |
|------|------|
| 入力 | 左手 `gamepad.buttons[5]`（`oculus-touch-v3` の `y-button`） |
| 検出 | 毎フレームポーリング + **エッジ検出**（押下の瞬間のみ。長押し連打防止） |
| 動作 | メインメニュー表示 ↔ 非表示 |
| メニュー非表示時 | 開いていたサブパネルもすべて閉じる |

初版では **Y 固定**。Menu ボタンは P5 で追加検討（[§10](#10-実装フェーズ) 参照）。

### 5.2 メニュー内操作

| 項目 | 仕様 |
|------|------|
| 手段 | コントローラー **トリガー（select）** によるレイキャスト |
| フィードバック | 押下時の色変化。ハプティクスは対応端末のみ（任意） |

### 5.3 テレポート抑止（D-05）

| 状態 | テレポート |
|------|------------|
| メインメニュー非表示 | 従来どおり（`teleport` / `both` モード時） |
| メインメニュー表示中 | **テレポート無効**（`_tryTeleportFromController` をスキップ） |
| サブパネルのみ表示中 | メインメニューが表示されている間は同様に無効 |

スムーズ移動・スナップターン・ジャンプはメニュー表示中も継続可能とする。

### 5.4 チャット入力（D-02）

| 項目 | 仕様 |
|------|------|
| 方式 | **Quest ブラウザのシステムキーボード** |
| 実装方針 | 入力欄フォーカス時に OS キーボードを起動。three-mesh-ui 単体の仮想キーボードは使わない |
| 技術 | 非表示またはオーバーレイ用の `<input>` / `<textarea>` にフォーカスし、`focus()` でシステム KB を起動するパターンを検討。実装時に Quest 実機で動作確認必須 |
| 送信 | 既存 `ChatManager` の送信ロジックを呼ぶ |

## 6. UI レイアウト

### 6.1 メインメニューバー（第 1 層）

```
┌─────────────────────────────────────────────────────────┐
│                    （HMD 視野・上側はワールド）              │
│                                                         │
├─────────────────────────────────────────────────────────┤
│ [管理][Mic][Spk][Chat][Stamp][Help][Restart][設定][退出] │  ← Y で表示
└─────────────────────────────────────────────────────────┘
```

| 項目 | 仕様 |
|------|------|
| 配置 | カメラに親付け。前方やや下、距離 0.8〜1.2 m、下向き 15〜25° |
| 追従 | **ヨー（水平回転）のみ**追従 |
| 初期状態 | 非表示 |
| スタイル | 半透明ダーク背景、角丸、アイコン + 短ラベル（i18n） |

**ビデオ項目は含めない**（D-01）。

### 6.2 サブパネル（第 2 層）

メニュー項目押下で、メインバーの **上方** にパネルを表示する。

| 項目 | 仕様 |
|------|------|
| 同時表示 | 原則 **1 パネルのみ**（チャットとスタンプは別パネル。同時には開かない） |
| 閉じ方 | パネル内「×」／同じメニュー項目の再押下／メインメニュー非表示（Y） |

### 6.3 絵文字パネル（D-04）

| 項目 | 仕様 |
|------|------|
| 起動 | メインメニューの「スタンプ」項目 |
| 独立性 | **チャットパネルとは別 UI**。チャットを開いていなくてもスタンプパネル単体で開ける |
| 内容 | 既存 `ChatManager` の絵文字一覧（`emojiList`）をグリッド表示 |
| 動作 | 選択で既存の絵文字送信処理を呼ぶ |

## 7. メニュー項目一覧

| VR ID | 既存 2D 要素 | 動作 | サブパネル |
|-------|-------------|------|------------|
| `admin` | `#admin-menu-btn` | 管理者のみ表示 | 管理クイックメニュー（透明化／飛行／高速／管理画面リンク） |
| `mic` | `#mic-btn` | 即時トグル | なし |
| `speaker` | `#speaker-btn` | 即時トグル | なし |
| `chat` | `#chat-container`（統合） | パネル表示 | チャット（一覧 + Quest KB 入力） |
| `stamp` | `#stamp-btn` | **独立パネル** | 絵文字グリッド |
| ~~`video`~~ | `#video-btn` | **VR では提供しない** | — |
| `help` | `#help-btn` | パネル表示 | 操作方法テキスト |
| `restart` | `#restart-world-btn` | 確認ダイアログ | はい／いいえ |
| `settings` | `#settings-btn` | パネル表示 | 全設定項目（§8） |
| `logout` | `#logout-btn` | 確認ダイアログ | ロビー戻り／ログアウト |

### 7.1 チャット統合

| 項目 | 仕様 |
|------|------|
| VR 中の `#chat-container` | 常時表示しない |
| 開き方 | VR メニュー「チャット」のみ |
| ロジック | `ChatManager` の受信・送信・モデレーション表示を再利用 |
| 入力 | Quest システムキーボード（§5.4） |

### 7.2 ビデオ配信（D-01）

| 項目 | 仕様 |
|------|------|
| VR メニュー | ビデオ項目なし |
| 既存配信中 | VR 入室時の挙動は実装時に定義（推奨: 入室前に停止を案内。強制停止は別途検討） |
| `#video-modal` | VR 中は開けない |

## 8. 設定パネル（D-03）

既存 `#settings-modal`（`MenuManager`）と **同等の全セクション・全項目** を VR パネルに実装する。

### 8.1 一般（`general-section`）

| 項目 | 要素 ID | VR 実装要件 |
|------|---------|-------------|
| 言語 | `#language` | 実装必須。変更は `MenuManager` 経由 |

### 8.2 音声（`audio-section`）

| 項目 | 要素 ID | VR 実装要件 |
|------|---------|-------------|
| マイクテスト | `#mic-test-btn`, `#settings-mic-analyzer` | 可能なら実装。困難なら UI + 「VR では利用できません」 |
| 使用マイク | `#micDevice` | 実装必須（デバイス一覧は Quest 制約内） |
| 使用スピーカー | `#speakerDevice` | 実装必須 |
| マイク音量 | `#micVolume` | 実装必須 |
| スピーカー音量 | `#speakerVolume` | 実装必須 |

### 8.3 描画（`draw-section`）

| 項目 | 要素 ID | VR 実装要件 |
|------|---------|-------------|
| 描画距離 | `#viewDistanceM` | 実装必須 |
| 画面表示（1/3人称） | `#viewModeToggle` | **UI 表示は必須**。VR 中は一人称固定のため、操作は無効または説明付きで非推奨表示でも可 |
| ハイコントラスト | `#highContrastToggle` | 実装必須 |
| 描画品質 | `#graphicsTier` | UI 必須。VR 中は自動 low の注記を表示 |
| 露出 | `#toneMappingExposure` | 実装必須 |
| ピクセル比 | `#pixelRatioCap` | UI 必須。VR 中は最大 1 の注記を表示 |
| 描画範囲の表示 | `#showViewRangeSpheres` | 実装必須 |
| プロモード | `#proModeToggle` | UI 必須。VR 中は意味が薄い旨の説明を表示可 |
| 開発者モード | `#developerModeToggle` | 実装必須 |

### 8.2〜8.3 の「UI のみ」扱い

実装が困難と判断した項目は以下を満たすこと。

- ラベル・説明文・コントロール見た目は 2D 設定と対応させる
- 操作は `disabled` 相当とし、理由を短い文言で表示（例: 「VR では利用できません」）
- `MenuManager` の内部状態を壊さない（読み取り専用でも可）

## 9. 技術要件

### 9.1 新規モジュール（案）

```
addons/webxr-vr/client/
  vr-quick-menu.js           # メイン／サブパネル管理、表示状態
  vr-quick-menu-input.js     # Y ボタン検出
  vr-menu-actions.js         # MenuManager / ChatManager 委譲
  vr-settings-panel.js       # 設定パネル UI
  vr-chat-panel.js           # チャット + システム KB 連携
  vr-stamp-panel.js          # 絵文字独立パネル
  assets/                    # MSDF フォント等
```

### 9.2 three-mesh-ui

- 依存パッケージとして追加
- レンダループ内で `ThreeMeshUI.update()` を実行
- VR セッション開始時にシーンへ attach、終了時に detach

### 9.3 既存コードとの接続

| 既存 | 接続 |
|------|------|
| `WebXRLocomotion` | メニュー表示フラグを参照しテレポート抑止。Y 検出の統合 |
| `MenuManager` | `toggleMic()`, `openSettings()` 相当を公開 API 化して委譲 |
| `ChatManager` | 送信・メッセージ更新・絵文字送信を再利用 |
| `init.js` | セッション start/end で VR メニュー lifecycle |
| `metaverse-i18n.js` | ラベル文言 |

### 9.4 2D UI との共存

| 状態 | `#menu-bar` | `#chat-container` | `#video-modal` |
|------|-------------|-------------------|----------------|
| VR 没入中 | 非表示または無効 | 非表示 | 開けない |
| VR 終了後 | 従来どおり | 従来どおり | 従来どおり |

## 10. 実装フェーズ

| フェーズ | 内容 | 完了の目安 |
|----------|------|------------|
| **P0** | Y トグル + 下部バー骨格 + レイキャスト + テレポート抑止フラグ | メニュー表示／非表示、テレポート停止 |
| **P1** | Mic / Speaker 即時トグル | 音声系 VR 操作 |
| **P2** | チャットパネル + Quest システム KB | US-03 |
| **P3** | スタンプ独立パネル | US-04 |
| **P4** | 設定全項目（UI のみ含む）+ Help / Restart / Logout / Admin | US-05 |
| **P5** | 実機調整、位置・サイズ、**Menu ボタン割り当て追加**、他機種 | 受け入れ基準クリア |

## 11. 受け入れ基準

1. Quest 実機（HTTPS）で VR 入室後、**Y 1 回**で下部メニューが表示される
2. **Y 再押下**でメニューとサブパネルが消える
3. メニューに **ビデオ項目がない**（または常に無効で配信開始できない）
4. **チャット**から Quest システムキーボードでメッセージ送信でき、他プレイヤーに届く
5. **スタンプ**がチャットとは別パネルで開き、絵文字送信できる
6. **設定**に一般・音声・描画の全項目が表示される（困難項目は UI のみで理由表示）
7. メニュー表示中、右トリガーで **テレポートしない**
8. メニュー非表示時、従来どおりテレポートできる（該当モード時）
9. VR 終了後、2D UI が通常どおり動作する
10. `webxr-vr` 無効時は本機能が一切動かない

## 12. 非機能要件

| 区分 | 要件 |
|------|------|
| パフォーマンス | 没入中 FPS を大きく低下させない |
| 障害耐性 | VR メニュー init 失敗時も VR 入室・移動は継続 |
| i18n | ja / en / zh |
| 権限 | 管理メニューは管理者のみ |
