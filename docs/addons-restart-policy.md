# アドオン有効化と再起動ポリシー

アドオンの有効／無効は SQLite（`db/addons_registry.db` の `addon_enabled`）に保存されます。設定を変更しただけでは **実行中のプロセスに読み込まれたコードは変わりません**。

## 反映手順

1. 管理画面 `/admin.html` の「アドオン」でトグルを変更し保存する（または `POST /admin/addons/enabled`）。
2. **Node.js プロセスを再起動**する（`nodemon` / `systemd` / PM2 / 手動など運用に合わせる）。

素の `node server.js` のみでは、サーバー自身が自動再起動しません。プロセスマネージャで再起動ポリシーを組むか、手動で止めて起動し直してください。

## 理由（単一プロセス・ESM）

ES モジュールは読み込み後にキャッシュされるため、ファイルを差し替えても同一プロセス内では確実なアンロードが困難です。本プロジェクトでは **プロセス再起動**で一貫した挙動を優先しています。
